How it works

O.C.G.A. § 48-5-343 doesn't leave the sequence up to interpretation. Every scenario the system produces has to clear it in order, and every one gets validated against Georgia statute and IAAO dispersion standards before it's even eligible for delivery — not reviewed after the fact, gated before.

01

Verify the input data

Parcel and sales records get rebuilt and reconciled before anything downstream trusts them.

02

Diagnose the ratio

Every sale is stratified by property class and neighborhood; the study runs at the stratum level, not one countywide average.

03

Calibrate land first

Land value gets corrected before anything built on it does, so downstream cost corrections start from a true base.

04

Model cost & depreciation

Replacement cost starts from national tables, then gets corrected class by class against real local sales. Depreciation is fit from what older properties actually show, with several methods scored against each other.

05

Validate for compliance

Coefficient of dispersion, price-related differential, and assessment-ratio band all have to clear Georgia's own thresholds, and the same check runs no matter which model produced the scenario.

06

Deliver board-ready

A partial-data result gets flagged as a pilot or blocked outright — never delivered quietly as final.

Standing rules

  • No method grades its own homework. The validation layer runs identically regardless of which valuation model produced the scenario.
  • Holdout, every time. A portion of sales is held out and never touched during calibration, so the fit gets checked against data it hasn't seen.
  • Document the correction, not just the number. Every class-by-class cost correction carries its data support, method, and confidence — never applied as one blanket adjustment.
  • Coverage before delivery. Nothing reaches the county without clearing a coverage threshold first.
